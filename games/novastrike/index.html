Arcade game

NOVA STRIKE

A vertical pixel-art shoot 'em up with endless stage progression, boss fights, power-ups, generated retro visuals, and chiptune audio built entirely in the browser.

Open project Back to projects
Controls

Move with arrow keys or WASD, fire with Z/Space, and bomb with X. Touch controls are also supported.

Run locally

Serve the game folder over HTTP and open it in a browser, because ES modules do not work from file://.

Project

Created in plain JavaScript with canvas rendering and WebAudio, no dependencies or build step.
